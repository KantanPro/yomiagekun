# 読み上げくん

ブログの内容をAIが要約して読み上げてくれるアクセシビリティプラグインです。

**Version: 1.1.0** | **Last Updated: 2026-09-28**

## 機能

- **AI要約**: OpenAI APIを使用してブログの内容を要約（簡略・詳細）。要約は記事ごとに保存し、記事を更新するまで作り直さない
- **全文読み上げ**: 「完全」は要約せずに本文をそのまま読む（APIキーなしでも使える）
- **音声読み上げ**: Web Speech APIを使用。文ごとに区切って読むので長い記事でも途中で止まらない
- **操作パネル**: アイコンを押すと、読み方・再生/一時停止・停止・速さ（0.8〜1.5倍）を選べる。選択はブラウザに記憶
- **アクセシビリティ対応**: キーボード操作・スクリーンリーダーへの状態通知・ダークモードに対応
- **レスポンシブ**: スマホではタップでパネルが開く。下固定メニューのあるテーマでも隠れない位置に出す

## インストール

1. プラグインフォルダを `/wp-content/plugins/yomiagekun/` にアップロード
2. WordPress管理画面でプラグインを有効化
3. 設定 > 読み上げくん から設定を行う

## 設定

### 必要な設定

1. **OpenAI API Key**: OpenAI APIのキーを設定（未設定なら「完全」だけが使える）
2. **プラグインを有効にする**: チェックを入れて有効化

### オプション設定

- **要約に使うモデル**: OpenAI のモデル名（既定: gpt-4o-mini）
- **音声の性別**: 男性/女性から選択（端末に入っている日本語音声から選ぶ）
- **読み上げ速度 / 要約の精度**: 最初に選ばれている値。訪問者は画面上で変更できる
- **アイコン画像**: カスタムアイコンをアップロード可能（PNG/JPEG/GIF/WebP）
- **表示するカテゴリー**: 選んだカテゴリーの記事だけに表示

## 使用方法

1. ブログ記事ページにアクセス
2. フローティングアイコンをクリック（タップ）して操作パネルを開く
3. 読み方（簡略・詳細・完全）を選んで「読み上げる」を押す

## 要件

- WordPress 5.0以上
- PHP 7.4以上
- モダンブラウザ（Web Speech API対応）

## 注意事項

- OpenAI APIの使用には料金が発生します
- 音声読み上げはブラウザのWeb Speech APIを使用します
- 一部のブラウザでは音声合成機能が制限される場合があります

## セキュリティ

- APIキーは管理画面でのみ扱い、記事ページには出力しない（伏せ字で表示）
- 読み上げの対象は「公開済み・パスワードなし・対象カテゴリー」の投稿だけ。下書き・非公開記事の本文は返さない
- 要約は記事×読み方ごとに post meta（`_yomiagekun_summary_simple` / `_detailed`）へ保存し、同じ記事で何度も課金しない
- 要約の新規作成は IP ごとに 10 分 20 回まで
- ページキャッシュで期限切れの nonce が配られて失敗しないよう、読み上げの取得には nonce を使っていない（公開記事の本文しか返さないため）
